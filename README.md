# M7000 UI
<img src="./M7000Tray/Assets/app.png">

Трей-приложение для мониторинга трафика на роутерах TP-Link с лимитом интернета.

## Описание

Приложение работает в системном трее, автоматически проверяет использованный трафик на роутере TP-Link через внутренний API и уведомляет об оставшихся гигабайтах. При получении новых SMS от роутера показывает системные уведомления.

## Требования

- **ОС:** Windows 10 19041 (20H2) или новее
- **.NET 10.0 SDK** (установлены версии 10.0.111 / 10.0.201 / 10.0.303)
- **Windows App SDK 2.0** (подхватывается через NuGet)

## Сборка

```bash

dotnet build

# Собрать Release
dotnet build -c Release

# Восстановить пакеты и собрать Release
dotnet restore && dotnet build -c Release
```

## Запуск из IDE / `dotnet run`

```bash
cd M7000Tray
dotnet run
```

Запускает приложение в режиме отладки. Откроется трей-иконка и окно настроек.

## Публикация (portable / self-contained)

```bash
# Портативная сборка (требуется установленный .NET 10 runtime)
dotnet publish -c Release -r win-x64 --self-contained false -o publish

# Самодостаточная сборка (включает runtime)
dotnet publish -c Release -r win-x64 --self-contained true -o publish
```

> **Важно:** при публикации в режиме `WindowsPackageType="None"` (unpackaged) автоматически копируются XAML-ресурсы (.pri, .xbf) в папку `publish`, без которых приложение падает при старте.

## Как работает

1. **Запуск** → приложение создаёт мьютекс (однократный запуск), помещает иконку в трей.
2. **Опрос роутера** → каждую минуту через `RouterClient.PollAsync()` запрашивает использованный трафик.
3. **Новой SMS** → показывает всплывающее уведомление Windows (AppNotification).
4. **Настройки** → левый клик по иконке открывает окно настроек (WebView2): IP роутера, логин, пароль.
5. **Автозапуск** → при первом запуске предлагает добавить себя в автозагрузку.

## Настройки

Настройки хранятся в файле `settings.json` (путь определяется через `Settings.Load()`).

| Параметр | Описание |
|---|---|
| `RouterIp` | IP-адрес роутера (по умолчанию `192.168.1.1`) |
| `PasswordProtected` | Пароль от веб-интерфейса администратора |
| `LimitGb` | Лимит трафика в ГБ |
| `UsedBytes` | Использованные байты (обновляется автоматически) |

## Устранение неполадок

| Проблема | Решение |
|---|---|
| Приложение не запускается | Убедитесь, что установлен .NET 10.0 Desktop Runtime |
| Окно настроек не открывается | Проверьте, что WebView2 runtime установлен |
| Ошибка подключения к роутеру | Проверьте IP и пароль в настройках, роутер должен быть в той же сети |
