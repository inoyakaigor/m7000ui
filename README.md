# M7000 UI
<img src="./M7000Tray/Assets/app.png">

Трей-приложение для мониторинга трафика на роутерах TP-Link с лимитом интернета.
Должно работать со всей линейкой M7000, M7005, M7010, M7350, M7352, M7400, M7450, M7750, M8550, но проверялось только на M7000.

## Описание

Приложение работает в системном трее. Раз в минуту оно заходит в веб-интерфейс роутера TP-Link (адрес `192.168.0.1`) через его внутренний API и:

- рисует в трее кольцо остатка трафика пакета;
- показывает уведомление Windows о каждом новом SMS;
- показывает в окне настроек заряд батареи, уровень сигнала, 4G и роуминг.

## Требования

- **ОС:** Windows 10 19041 (20H2) или новее
- **.NET 10.0 SDK** — для сборки
- **Windows App Runtime 2.0** — должен быть установлен в системе. Приложение не встраивает Windows App SDK в папку сборки: в self-contained режиме SDK 2.0 падает при регистрации уведомлений (не находит `Microsoft.WindowsAppRuntime.Insights.Resource.dll`).

## Сборка

```bash
dotnet build "M7000 UI.slnx" -p:Platform=x64
```

## Запуск из IDE / `dotnet run`

```bash
cd M7000Tray
dotnet run -p:Platform=x64
```

Появится только иконка в трее — главного окна у приложения нет, настройки открываются из меню иконки.

## Публикация

```bash
dotnet publish M7000Tray/M7000Tray.csproj -c Release -r win-x64 -p:Platform=x64 --self-contained true -o publish
```

`--self-contained true` кладёт в папку .NET runtime. Windows App Runtime 2.0 всё равно нужен в системе (см. «Требования»).

> **Важно:** в unpackaged-режиме (`WindowsPackageType=None`) `dotnet publish` теряет скомпилированный XAML (`.pri`, `.xbf`). В `M7000Tray.csproj` есть шаг, который докладывает их в `publish`, — без них приложение падает при старте.

## Как работает

1. **Запуск.** Мьютекс не даёт запустить вторую копию. Иконка появляется в трее, первый опрос идёт сразу.
2. **Проверка сети.** Перед каждым опросом приложение узнаёт MAC устройства на `192.168.0.1` через ARP — без логина и без HTTP, роутер не тратит попытку входа. MAC своего роутера приложение запоминает при первом успешном опросе. Если MAC другой (подключились к чужой сети, где тоже `192.168.0.1`), опроса и входа нет, в трее — обычная иконка приложения и подсказка «Другая сеть — роутер M7000 не найден». Если по ARP никто не ответил — «Нет связи с роутером». Когда сеть появляется или меняется (выход из сна, другой Wi-Fi), опрос запускается через 3 секунды, не дожидаясь минуты.
3. **Опрос роутера** раз в минуту: вход, модуль `status` (трафик, батарея, сигнал, число непрочитанных SMS) и первая страница входящих SMS. Сессии к роутеру открываются строго по одной.
4. **Иконка в трее.**
   - Кольцо — остаток трафика пакета: полное — 100%, нет кольца — 0%.
   - Цвет кольца: голубой 100–90%, зелёный до 40%, жёлтый до 10%, красный ниже.

   <img src="./tray-states.png" alt="Состояния иконки в трее">

   Слева направо: батарея ниже 10%, непрочитанное SMS, процент, процент на паузе, нет данных, ошибка.

   - Внутри кольца показывается одно из трёх, по приоритету — если выполняются несколько условий, побеждает верхнее:
     1. красная батарейка — заряд роутера ниже 10% (важнее всего: роутер скоро выключится);
     2. золотистый конверт — есть непрочитанные SMS; гаснет, когда SMS помечено прочитанным;
     3. процент остатка — всё в порядке.
   - Пауза — не отдельное состояние, а оверлей: пока опрос приостановлен, белая пауза в правом нижнем углу рисуется поверх любого из трёх.
   - Серое кольцо с «?» — данных ещё нет (первые секунды после запуска).
   - Жёлтый треугольник — ошибка или нет связи: заменяет всю иконку, причина видна в подсказке.
   - Иконка роутера (как у exe) — компьютер в чужой сети, приложение ждёт свой роутер.
5. **Мышь.**
   - Левый клик открывает админку роутера `http://192.168.0.1/login.html` и ставит опрос на паузу на 5 минут — иначе опрос приложения выкинет вас из админки.
   - Правый клик открывает меню: «Настройки», «Обновить», «Не обновлять» (5/10/20 минут), «Выход».
6. **Новое SMS** — уведомление Windows с текстом и кнопкой «Пометить прочитанным». Кнопка работает и когда приложение закрыто: Windows его запустит.
7. **Неверный пароль** — только когда роутер прямо ответил «неверный пароль» (`result 1`); если ответ на вход не разобрался, вход повторяется в новой сессии. Опрос останавливается до нового сохранения пароля или «Обновить» в меню. После 10 неудачных входов роутер блокирует вход на 2 часа, поэтому приложение не повторяет попытки.
8. **Автозапуск** включён по умолчанию (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`), выключается галочкой в окне настроек.

## Лимит пакета и остаток

Приложение само считает, сколько трафика ушло из пакета: каждую минуту прибавляет, насколько вырос счётчик роутера с прошлого опроса. Размер пакета и стартовую точку задаёте вы в окне настроек.

- **Лимит пакета, ГБ** — размер пакета у оператора.
- **Осталось сейчас, ГБ** — сколько трафика осталось на самом деле. Поле заполняется текущим остатком; если он разошёлся с данными оператора (например, с SMS о балансе), впишите правильное число и нажмите «Сохранить» — приложение пересчитает расход.
- **Пакет продлён** — нажимайте, когда оператор продлил пакет или вы купили новый и трафик снова полный. Кнопка ставит «Осталось» равным лимиту, затем нажмите «Сохранить» — расход начнётся с нуля. Если новый пакет другого размера, сначала поменяйте «Лимит пакета».

Пока поля лимита или остатка изменены и не сохранены, строка над прогресс-баром и сам бар показывают введённые значения с пометкой «не сохранено». Иконка в трее и файл настроек меняются только после «Сохранить».

## Настройки

Хранятся в `%APPDATA%\Igor Zviagintsev\M7000\settings.ini`. Файл можно править руками: приложение подхватит изменения при следующем опросе.

| Параметр | Описание |
|---|---|
| `PasswordProtected` | Пароль от веб-интерфейса, зашифрован DPAPI (расшифровывается только под вашей учёткой Windows) |
| `LimitGb` | Лимит пакета, ГБ |
| `UsedBytes` | Израсходовано из пакета, байт (считает приложение) |
| `LastRouterTotal` | Последнее значение счётчика трафика роутера, байт |
| `RouterMac` | MAC своего роутера — запоминается при первом успешном опросе, сбрасывается при сохранении нового пароля |
| `LastSmsTime` | Время последнего SMS, о котором уже было уведомление |
| `AutoStart` | Запуск вместе с Windows (`True`/`False`) |

Адрес роутера зашит в коде: `192.168.0.1` (`RouterClient.RouterUrl`).

## Устранение неполадок

| Проблема | Решение |
|---|---|
| Приложение не запускается или сразу закрывается | Установите Windows App Runtime 2.0 и посмотрите `crash.log` рядом с `settings.ini` |
| Жёлтый треугольник в трее | Наведите курсор на иконку — в подсказке причина; полный стек — в `crash.log` |
| «Роутер отклонил пароль» | Роутер ответил «неверный пароль» (`result 1`). Проверьте пароль в админке и сохраните его заново в окне настроек или нажмите «Обновить» в меню — это одна попытка входа. Если вход заблокирован, подождите 2 часа |
| «Нет связи с роутером» | Компьютер должен быть подключён к сети роутера; адрес — `192.168.0.1`. Сетевые сбои в `crash.log` не пишутся |
| «Другая сеть — роутер M7000 не найден» в своей сети | Роутер сменился или сброшен: сохраните пароль заново в окне настроек или удалите `RouterMac` из `settings.ini` — приложение запомнит новый MAC |
| Иконки нет в трее | Windows могла убрать её в скрытые значки (^) — перетащите на панель задач |
